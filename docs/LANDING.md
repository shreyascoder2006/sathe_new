# SMART CAMPUS 360 — Landing Page Documentation

This is the landing page and live digital-twin demo integrated from `Sathe_landing`.

## Overview
- **Location**: Hosted via Next.js at `/` and `/landing` (served from `public/landing.html`).
- **Dependencies**: Uses Three.js r128 loaded from cdnjs. All styles and scripts are completely self-contained within the HTML document.
- **Key Sections**:
  1. **Hero**: 3D twin rotating with live scenario feed updating every ~10 seconds.
  2. **Scroll Exploration**: Dynamic camera flythrough transitions across campus landmarks.
  3. **Understand**: CCTV monitoring count climbing to 420 with live detection bounding boxes.
  4. **Simulate**: Interactive crowd density slider with live responsive 3D particle updates.
  5. **Act**: Decision approval flow showing rapid latency and efficiency gains.
  6. **Canteen**: Demand forecasting by pickup window and crowd balancing.
  7. **Operations & Maintenance**: Predictive failure work orders and scheduled energy shutdowns.
  8. **Emergency**: Interactive evacuation drill simulation with multi-path routing overlays.
  9. **Roles**: Five distinct persona perspectives (Admin, Teacher, Security, Maintenance, Student).
