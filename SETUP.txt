NEXUS Campus — quick start
==========================
Requires Node 20+ (built on Node 22).

  npm install
  npm run db:seed      # creates backend/prisma/dev.db + ~13k seeded rows
  npm run dev          # http://localhost:3000

A seeded backend/prisma/dev.db is already included, so you can skip db:seed
and just run `npm install && npm run dev`. Use `npm run db:reset` to wipe/reseed.

AI: .env already contains a working GROQ_API_KEY (model openai/gpt-oss-120b).
The app also works with NO key (deterministic rule-based fallback), or swap in
GEMINI_API_KEY / ANTHROPIC_API_KEY — backend/ai/llm.ts auto-detects.

Not included: node_modules, .next  (regenerated by npm install / npm run dev)
